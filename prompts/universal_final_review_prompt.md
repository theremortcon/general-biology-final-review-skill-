# 通用期末复习资料生成 Prompt

你将读取课程资料，并生成一套适合期末闭卷考试的中文复习资料。

## 输入材料

优先阅读：

1. `outputs/_course_context.md`
2. `outputs/_materials_index.md`
3. `markdown/` 中的所有 Markdown 文件
4. 必要时回看 `materials/` 中的原始课件

## 生成目标

请生成以下文件：

1. `outputs/总复习知识框架.md`
2. `outputs/名词解释背诵表.md`
3. `outputs/易混概念对比表.md`
4. `outputs/重点过程机制整理.md`
5. `outputs/可能考题.md`
6. `outputs/三天冲刺计划.md`
7. `outputs/错题与薄弱点追踪表.md`

## 重要要求

- 全部使用中文。
- 面向期末考试，不要只做摘要。
- 资料中反复出现的标题、表格、图示、红字、加粗词优先整理。
- 对“定义、分类、结构、功能、过程、区别、意义”重点整理。
- 对图示、结构图、流程图、组织切片图、表格，标注“可能出识图题/表格题”。
- 对资料中缺失但考试可能需要的内容，标注“需要结合教材或老师课堂补充”，不要假装资料里有。
- 使用 Markdown 表格和树状结构。
- 语言要适合背诵，不要写成论文。

## 输出格式

### 总复习知识框架

```markdown
# 总复习知识框架

## 一、课程总体结构

## 二、考试复习主线

## 三、章节知识框架

### 第 X 章：章节名

#### 1. 本章核心问题
#### 2. 知识树
#### 3. 必背概念
#### 4. 重点过程 / 机制 / 步骤
#### 5. 易混点
#### 6. 可能考题
#### 7. 复习优先级
```

### 名词解释背诵表

```markdown
| 序号 | 章节 | 名词 | 定义 | 关键词 | 常见考法 | 记忆提示 |
|---|---|---|---|---|---|---|
```

### 易混概念对比表

```markdown
| 章节 | 易混概念 A | 易混概念 B | 核心区别 | 共同点 | 记忆提示 | 可能考法 |
|---|---|---|---|---|---|---|
```

### 重点过程机制整理

```markdown
## 过程/机制名称

### 所属章节
### 一句话概括
### 流程
A → B → C → D

### 每一步解释
### 易错点
### 可能考法
```

### 可能考题

按章节和题型输出：

```markdown
# 可能考题

## 第 X 章

### 名词解释
### 选择题
### 填空题
### 判断题
### 简答题
### 识图题 / 表格题 / 材料题
### 参考答案
```

### 三天冲刺计划

```markdown
# 三天冲刺计划

## Day 1：搭框架 + 抓主干
## Day 2：背概念 + 攻易混点
## Day 3：刷题 + 查漏补缺
```

每天包含：

- 今日目标
- 任务清单
- 预计用时
- 检查标准
- 必须产出

## 文档解析质量检查

在生成复习资料前，请检查资料转换质量：

1. 每个课件文件是否都有对应 Markdown？
2. Markdown 是否保留章节标题？
3. 是否有大量页面只有图片没有文字？
4. 是否遗漏表格、流程图、结构图？
5. 是否需要运行 Docling 兜底？

如果资料明显含有大量图示，复习资料必须加入“可能出识图题/结构题”的提示。
