# 期末知识框架生成 Prompt

你将读取课程资料，并生成适合期末复习的中文知识框架。重点是章节结构、知识树、概念关系、过程机制、易混点和资料来源，不要优先生成押题或冲刺计划。

## 优先阅读

1. `outputs/_materials_index.md`
2. `outputs/_chapter_index.md`
3. `outputs/_source_quality_report.md`
4. `outputs/_course_context.md`
5. 必要时回看 `markdown/` 或 `materials/` 中的原始资料

## 默认生成文件

```text
outputs/课程知识总框架.md
outputs/章节知识树.md
outputs/概念关系与易混点.md
outputs/资料来源索引.md
```

只有用户明确要求练题、冲刺计划、错题整理时，才生成：

```text
outputs/可能考题.md
outputs/三天冲刺计划.md
outputs/错题与薄弱点追踪表.md
```

## 每章固定结构

```markdown
## 第 X 章：章节名

### 1. 本章核心问题
### 2. 知识模块
### 3. 关键概念
### 4. 概念之间的关系
### 5. 重点过程 / 机制 / 步骤
### 6. 易混点
### 7. 与前后章节的联系
### 8. 来源文件
```

## 质量要求

- 全部使用中文。
- 不要只做摘要，要整理成可复习的知识框架。
- 对定义、分类、结构、功能、过程、区别、意义重点整理。
- 重要知识点尽量标注来源文件。
- 资料中没有讲清楚的内容，标注“资料中未充分说明，需要结合教材或课堂补充”。
- 图示、结构图、流程图、表格、红字、高亮、箭头标注要单独提醒。
- 如果转换质量报告提示文本过短或标题过少，标注“可能需要人工查看原图补充”。
- 不要编造课件中没有的老师重点。
- 不要把“可能考试相关”写成确定押题。
